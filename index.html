Minha Playlist

Suas músicas (.mp3) e videoclipes (.mp4) com letra, direto no celular, tablet ou computador.

▶ Abrir a playlist

📦 O que vem no pacote

MinhaPlaylist.html (o aplicativo), sw.js (guarda tudo para funcionar sem internet), Icone de Musica.png e um LEIA-ME.

📱 Instalar no celular ou tablet

  1. Baixe o .zip e, no app Arquivos, toque nele e escolha Extrair (por exemplo, para Download/Playlist).
  2. Coloque na mesma pasta as pastas das bandas com os .mp3 e .mp4. Para a letra, deixe um .lrc ou .txt com o mesmo nome da música.
  3. Abra um servidor local apontando para essa pasta (por exemplo, um app de servidor HTTP na porta 8080) e acesse http://localhost:8080/MinhaPlaylist.html no Chrome.
  4. Menu ⋮ → Adicionar à tela inicial. Depois de abrir uma vez com o servidor ligado, o app guarda o que precisa para funcionar offline.

Também dá para abrir o MinhaPlaylist.html direto pelo Arquivos com o Chrome, mas o modo offline automático (sw.js) só age quando aberto por um endereço (localhost ou https).

💻 Instalar no computador

  1. Extraia o .zip em uma pasta e coloque nela as pastas das bandas.
  2. No terminal, dentro da pasta, rode python -m http.server 8080 (ou use o Live Server do VS Code).
  3. Acesse http://localhost:8080/MinhaPlaylist.html no Chrome ou Edge e clique no ícone de instalar na barra de endereço.

💡 Dicas

  • Use Chrome ou Edge atualizados. Limpar os dados do navegador apaga o modo offline.
  • Na tela do vídeo, use ⛶ para ampliar e ✕ Tamanho normal para voltar; toque duas vezes no vídeo também alterna.
  • Na letra, use A−/A+ para o tamanho do texto, 🎯 para seguir a música e ⤢ para ler em tela cheia.
